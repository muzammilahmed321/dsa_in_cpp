# 📖 About

This repository contains the code I wrote while studying **Data Structures & Algorithms (DSA)** during my **3rd semester** at **NED University of Engineering & Technology**.

The majority of the programs are based on the **official DSA laboratory exercises** conducted throughout the semester. In addition, the repository includes a small collection of extra practice problems and coding challenges inspired by platforms such as **LeetCode** to further improve problem-solving skills.

The goal of this repository is to provide a complete reference for fundamental DSA concepts and their implementations in **C++**.

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/muzammilahmed321/dsa_in_cpp.git
```

## Navigate to the Repository

```bash
cd dsa_in_cpp
```

## Compile a Program

```bash
g++ filename.cpp -o output
```

Example:

```bash
g++ basic_link_list.cpp -o basic_link_list
```

## Run the Program

```bash
./basic_link_list
```

**Windows**

```bash
basic_link_list.exe
```
